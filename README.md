# 🛒 E-Commerce Website Using Django

A full-stack E-Commerce Website developed using Django that allows users to browse products, manage carts, place orders, simulate payments, generate invoices, and provide product feedback.

---

## 🚀 Features

* User Registration & Login Authentication
* Product Category Management
* Product Browsing & Details Page
* Shopping Cart Management
* Checkout & Payment Simulation
* Order Placement & Order Tracking
* Order History Management
* PDF Invoice Generation
* Product Feedback & Rating System
* Responsive UI using Bootstrap
* SweetAlert Notifications

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/ecommerce-website.git

cd ecommerce-website
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux/Mac

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install django
pip install django-bootstrap4
pip install reportlab
```

### Apply Migrations

```bash
python manage.py makemigrations

python manage.py migrate
```

### Run Server

```bash
python manage.py runserver
```
